This is a Countdown solver. Currently it is just an algorithm, but I want to expand it to be a playable game.

The rules for the numbers portion as as so:

There are six numbers chosen somewhat-randomly (usually by size, like 4 small numbers and 2 big numbers, usually in multiples of 25).
A three-digit number is randomly generated.
Utilizing addition, subtraction, multiplication and division, the player must get to the target
Numbers can only be used once
No zeros, and no fractions may be used.
